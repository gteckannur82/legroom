Before you install.

Windows
Windows 10 or Windows 11, 64-bit.
WebView2
Built into Windows 11 and current Windows 10. If it’s missing, the installer fetches it — that needs an internet connection once.
Fast scan
Optional. Needs administrator permission and an NTFS drive with a letter (C:, D: …). A normal scan works everywhere.
Your data
Everything runs on your PC. Legroom doesn’t upload your files or file lists.
Updating
Run the newer installer; it replaces the old version.
Uninstalling
Settings › Apps › Installed apps › Legroom. Put back or permanently remove anything Legroom set aside first.
